Adding one in code 
// lib/probe-guard/templates/laravel.ts
export const laravel: ProbeTemplate = {
  id: "laravel",
  name: "Laravel",
  detect: [{ cookie: "laravel_session" }],
  turnAway: ["/storage/logs", "/telescope", "/horizon"],
};

Drop a file in the folder and it shows up here and in scans. detect takes an image pattern, a probe path with a body match, a cookie or a response header; letThrough lists paths to skip a Block common probes rule for. "New template" in this card saves an entry list as a template with the same fields, minus the code.
